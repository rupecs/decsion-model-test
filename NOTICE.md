# Publication and model prerequisites

The dataset consists of synthetic authored research examples and proposed labels. It is not a collection of real customer records, independent legal annotation or production approval.

No new software or dataset licence is selected by this package. Public GitHub visibility is not itself a permissive licence grant. The owner should retain or explicitly choose the destination repository's intended terms; a receiving agent must not silently add MIT/Apache/CC terms.

The Google Gemma base checkpoint is **not included**. The operator must obtain and stage the original checkpoint through an approved process with any required licence/access acceptance. Model licence terms and upstream dependency licences are separate from this repository. No model weights or third-party package source are redistributed here.

`provenance/original_v14_source_snapshot.zip` contains this project's own generation/runtime source inventory, not downloaded Unsloth/PyTorch source. Internal historically named helper modules are code dependencies, not older dataset releases.
